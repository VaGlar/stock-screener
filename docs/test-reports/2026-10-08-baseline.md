## 3. Gaps (με προτεραιότητα)

### G1 — [FIXED, επιβεβαιωμένο] Zero-vs-missing-data στο scoring model
Το bug που περιγράφηκε στο προηγούμενο report (PR #13) — `if x and isinstance(x, (int, float))` αντί για `is not None` στο `score_stock()` — διορθώθηκε στο PR #14 (commit `c04add5`, merged). Fresh επαλήθευση σήμερα:
```
AT 52w high  (pct_from_high=0.0)   -> technicals: 11
1% BELOW high (pct_from_high=-0.01) -> technicals: 11   (πριν ήταν 7 vs 11)
```
Επίσης επιβεβαιώθηκε με grep ότι το falsy-zero pattern (`if gm and isinstance...` κ.λπ.) δεν υπάρχει πια πουθενά στο `score_stock()`. Real-zero values (0% margin, 0% growth, 0% ROIC, RSI 0) παράγουν πλέον σωστά flags (`🔴 Gross margin 0%`, `🔴 ROIC 0.0%`, `🟢 RSI 0 (oversold)`) αντί να προσπερνιούνται σιωπηλά. **Κλειστό.**

### G2 — [MEDIUM, ακόμα ανοιχτό] Unescaped HTML injection από external-sourced strings
**Πού:** `screener.py`, `build_html_report()` (π.χ. `{d['name']}`) και `performance_report.py` — τα πεδία `ticker`/`name`/`industry`/`sector` (από yfinance ή scraped Wikipedia tables) μπαίνουν σε f-string HTML χωρίς `html.escape()`.

**Αναπαραγωγή (fresh, σήμερα):**
```python
malicious_name = '<img src=x onerror=alert(1)>Evil Corp'
html = build_html_report([{'data': {'ticker':'EVL','name': malicious_name, ...}, ...}], {...})
# '<img src=x onerror=' βρίσκεται ΑΥΤΟΛΕΞΕΙ στο παραγόμενο HTML — ΑΚΟΜΑ ανοιχτό
```
Ίδιο impact assessment με πριν: χαμηλή πιθανότητα εκμετάλλευσης (απαιτεί vandalism σε Wikipedia ή "κακό" yfinance name), αλλά πραγματική απουσία output encoding. **Δεν διορθώθηκε ακόμα.**

### G3 — [MEDIUM, ακόμα ανοιχτό] `requirements.txt` ελλιπές
`requirements.txt` λιστάρει μόνο `yfinance==0.2.38` και `pandas==2.2.0`. Το `screener.py` κάνει `import numpy` που δεν είναι καταγεγραμμένο (διόρθωση vs το προηγούμενο report: μόνο το `screener.py` το κάνει αυτό — το `backtest.py` **δεν** κάνει import numpy απευθείας, επιβεβαιώθηκε με grep σήμερα). Το `build_watchlist.py` χρειάζεται `lxml`/`html5lib` για `pd.read_html()`, που εγκαθίστανται μόνο ad-hoc μέσα στα workflow YAML, όχι από το `requirements.txt`. **Δεν διορθώθηκε ακόμα.**

### G4 — [LOW, ακόμα ανοιχτό, unconfirmed] Πιθανό NaN leakage στο ROIC
`screener.py` — `ebit = q_income.iloc[:, i].get("EBIT") or q_income.iloc[:, i].get("Operating Income")`. Αν EBIT είναι `NaN` (συχνό σε πραγματικά yfinance data), το `NaN` είναι truthy στην Python, οπότε δεν γίνεται fallback, και το `NaN` μπορεί να διαδοθεί μέχρι ένα flag σαν `"🔴 ROIC nan%"`. **Δεν επιβεβαιώθηκε με πραγματικά δεδομένα** (δίκτυο προς Yahoo Finance εξακολουθεί να μπλοκάρεται — `curl` έδωσε HTTP 429 και σήμερα).

### G5 — [LOW, ακόμα ανοιχτό] Missing flags σε δύο σημεία του scoring
`screener.py:373` (SAM, `elif rg >= 0.10: s += 3` χωρίς flag) και `screener.py:394` (Catalyst, `elif num_analysts >= 8: s += 2` χωρίς flag) — επιβεβαιωμένο ότι παραμένουν ως έχουν.

### G6 — [LOW, ακόμα ανοιχτό] Καμία προστασία αν λείπει το `GMAIL_APP_PASSWORD`
`send_email()` σε `screener.py`/`performance_report.py` — αν το env var λείπει, `smtplib` θα πετάξει μη πιασμένο exception. Επιβεβαιωμένο αμετάβλητο.

### G7 — [LOW, ακόμα ανοιχτό] CI/CD hardening
Μόνο `weekly_screener.yml` έχει explicit `permissions:` (`contents: write`). Τα άλλα 3 βασίζονται στο org/repo default. Actions pinned σε major-tag (`@v4`/`@v5`), όχι SHA. Κανένα `CODEOWNERS` — επιβεβαιωμένο ότι εξακολουθεί να μην υπάρχει, παρότι τώρα υπάρχει και νέο `.claude/` directory που επίσης δεν προστατεύεται από `CODEOWNERS`. Κανένα workflow σε `pull_request`.

### G8 — [LOW, ακόμα ανοιχτό] Μη ιδεατή idempotency στο ledger
`log_recommendations()` δεν κάνει dedup ανά ημερομηνία/ticker — ένα διπλό manual re-run θα διπλογράψει γραμμές. Αμετάβλητο.

### G9 — [NEW, LOW] Νέο `.claude/` directory χωρίς CODEOWNERS/δική του τεκμηρίωση ελέγχου
Το PR #15 πρόσθεσε `.claude/agents/tester.md` και `.claude/commands/{test-baseline,test-changes}.md` στο repo.
